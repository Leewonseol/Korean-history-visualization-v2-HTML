# 1432–1449 연도별 조사 기록 (chronology)

> 각 연도의 '데이터셋 사건' 목록은 `node tools/build-research.mjs` 가 `src/data/events.js` 에서 자동 생성한다.

1437·1438·1439·1449는 사용자가 제시한 anchor 기사 설명만으로 `unverified_seed` 사건을 만들었다.

## 1. 매년 적용할 검색 항목(체크리스트)

군사 충돌 / 침입·추격·정벌 / 군사 지휘체계 / 병력 동원 / 군량·병기·화포 / 정찰·봉화·정보 수집 /
성곽·진·보·군현 설치 / 사민·입거·주민 정책 / 전사·부상·포로 / 포상·승진 / 처벌·지휘책임 /
전사자·유가족 예우 / 여진 세력과의 외교 / 명과의 관계 / 여진 내부 세력관계 / 4군 관련 정책 / 6진 관련 정책

권장 절차: 세종실록 월별 기사목록(세종 14년 12월 ~ 31년 7월)을 월 단위로 열람 → 위 항목 해당 기사 ID 기록 →
기사 안의 '치계/장계/회계/계' 인용 구간을 embedded document로 분리 → 실명 인물 전부 authority에 등록 →
행위가 확인되는 경우에만 relation 생성. 검색어 예: 야인, 올량합, 올적합, 홀라온, 파저강, 이만주, 범찰, 동창,
여연, 자성, 강계, 무창, 우예, 회령, 종성, 경원, 경흥, 온성, 부령, 부거, 도절제사, 절제사, 사민, 입거, 축성, 봉화.
