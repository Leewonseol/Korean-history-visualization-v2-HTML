# 1432–1449 연도별 조사 기록 (chronology)

> 이 문서는 **조사 기록**이다. "사건이 없다"와 "조사하지 못했다"를 구분해서 적는다.
> 각 연도의 'Coverage / Sources / Note'는 `node tools/build-research.mjs` 가 **coverage 레지스트리(`src/data/coverage.js`)**에서,
> '데이터셋 사건'은 `src/data/events.js`에서 자동 생성한다. 연도 상태를 사건 유무로 추론하지 않는다.

## 0. 근거와 접근 기록

| 단계 | 내용 |
|---|---|
| 1차 작업 세션 | sillok.history.go.kr · encykorea.aks.ac.kr · kyu.snu.ac.kr · db.itkc.or.kr · 위키문헌 등이 작업 환경의 네트워크 정책으로 모두 차단(egress 403). 원문을 직접 읽지 못함. 웹 검색 요약문은 데이터 근거로 쓰지 않음. |
| VALIDATED HISTORICAL SOURCE PACK v1 | 사용자가 접근 가능한 실록 페이지와 수동 대조한 seed set(1432-12-09~1449-07-07, 사건 46건 + 『세종실록』 지리지 4건 + 『서정록』 서지). 이 팩에 있는 내용만 `provenance: pack_v1_direct / pack_v1_derived`로 반영. **전수 추출이 아니다.** |
| 3차(감사) 세션 | 외부 사료 사이트 접근 불가 상태에서 pack v1만 ground truth로 데이터 전체를 감사(`audit_pre_fix.md`)하고 수정(`audit_post_fix.md`). 새 사건·인물·관계를 추가하지 않음. |
| 2차 작업 세션 | 같은 사이트가 여전히 차단되어, 이 세션에서도 원문을 직접 열람하지 못했다. pack v1 내용을 데이터로 옮기고 v2 이관 자료와 충돌하는 부분은 `discrepancies.md`에 기록했다. |

근거 계보: `pack_v1_direct` / `pack_v1_derived`(정규화 규칙 R1~R7) / `inherited_v2`(이전 데이터셋 요약, legacy) / `legacy_anchor_seed`(anchor였으나 pack에 없음) / `interpretation`.
pack v1 사건 안에서도 v2에서만 온 관계는 relation 단위로 `inherited_v2`를 붙였다. 날짜는 `dateMin~dateMax`(정밀도 DAY/MONTH/YEAR/UNKNOWN)로 적는다.

## 1. 매년 적용할 검색 항목(체크리스트)

군사 충돌 / 침입·추격·정벌 / 군사 지휘체계 / 병력 동원 / 군량·병기·화포 / 정찰·봉화·정보 수집 /
성곽·진·보·군현 설치 / 사민·입거·주민 정책 / 전사·부상·포로 / 포상·승진 / 처벌·지휘책임 /
전사자·유가족 예우 / 여진 세력과의 외교 / 명과의 관계 / 여진 내부 세력관계 / 4군 관련 정책 / 6진 관련 정책

권장 절차: 세종실록 월별 기사목록(세종 14년 12월 ~ 31년 7월, 윤달 포함)을 월 단위로 열람 → 위 항목 해당 기사 ID 기록 →
기사 안의 '치계/장계/회계/계' 인용 구간을 embedded document로 분리 → 실명 인물 전부 authority에 등록 →
행위가 확인되는 경우에만 relation 생성. 검색어 예: 야인, 올량합, 올적합, 우디거, 오도리, 홀라온, 파저강, 이만주, 범찰, 동창,
여연, 자성, 강계, 무창, 우예, 회령, 종성, 경원, 경흥, 온성, 부령, 부거, 도절제사, 절제사, 사민, 입거, 축성, 봉수, 연대.
