# 불일치·쟁점 기록 (discrepancies)

자동 생성되며, 사건 패널의 '불일치·쟁점'에도 표시된다.

## 서술 금지 사항 점검(데이터·스토리 문구 기준)

- 이만주 측 주장을 확정 사실로 바꾸지 않음 → E1432_03 CLAIM `contemporary_claim`.
- 조선 측 전과 수치를 독립 검증 수치로 쓰지 않음 → outcome에 `reportedBy` 표기.
- 여진 전체를 하나의 집단으로 합치지 않음 → 세력 7종 + '세력 미특정' 분리.
- 이만주를 전체 여진의 지배자로, 맹가첩목아·범찰·동창·임합라를 이만주의 부하로 만들지 않음 → 상하관계 edge 없음, 범찰 이동은 RESETTLEMENT(부하 편입 아님).
- 4군·6진을 파저강 정벌의 직접 결과로 단순화하지 않음 → 자성군 설치의 인과는 `sequence_only`.
- 1433 승전 뒤 침입이 끝났다고 쓰지 않음 → 1435 두 차례 침입 기록.
- 이만주가 항복했다는 서술 없음.
- 1449를 북방 문제 해결 시점으로 묘사하지 않음 → '작업상 종점'으로만 표기.
