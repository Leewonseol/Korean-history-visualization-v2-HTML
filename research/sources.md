# 사료 목록 (sources)

표는 `src/data/sources.js` 에서 `node tools/build-research.mjs` 로 자동 생성된다. 모든 링크는 클릭 가능한 원 URL이다.

## 구분 원칙

| 구분 | 의미 | 데이터에서 |
|---|---|---|
| 원문(1차) | 세종실록 기사 원문·국역 (`wda_` = 원문 화면, `kda_` = 국역 화면) | `sourceType=sillok`, `sourceLevel=primary` |
| 당대 편찬물 | 『서정록』 등 당대·근대 이전 편찬 자료 | `sourceType=seojeongnok`, `sourceLevel=contemporary_compilation` |
| 2차 자료 | 백과사전·연구서 | `sourceType=secondary_reference`, `sourceLevel=secondary` — 이것만으로는 `confirmed`가 될 수 없음(validateData가 차단) |
| 지리지 | 『세종실록』 지리지(연 단위 서술) | `sourceType=sillok`, `sourceLevel=contemporary_compilation`, `documentType=geography` |
| 검증 상태 | 원문 대조 여부 | `verification` = `pack_v1`(사용자 수동 검증) / `inherited_v2` / `seed_unverified` / `not_accessed` |

**작업 환경에서는 실록·백과·규장각 사이트가 차단되어 있어, 이 저장소의 작업 세션이 직접 원문을 대조한 사료는 없다.**
`pack_v1`은 사용자가 대조해 제공한 VALIDATED HISTORICAL SOURCE PACK v1에 근거한다(접근 기록은 `chronology_1432_1449.md` §0).
`not_accessed` 사료는 `validateData()`가 사건 근거로 쓰지 못하게 막는다.
